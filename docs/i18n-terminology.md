# Soltex Global — Multilingual Terminology Map

Status: **v1 (initial translation)** · Source language: **English (master)**
Applies to: `src/i18n/locales/{ru,zh,tr,ar,es}.json`

Every translation must use the terms below consistently. When a term is added or changed here,
update all five dictionaries in the same change.

## Global rules

| Rule | Detail |
|---|---|
| English is the master | Never edit English wording to suit a translation. Translations follow English meaning exactly — no added, removed or strengthened claims. |
| Keep untranslated | Soltex, Soltex Global, Soltex Group, SOLTEX GROUP LTD, Soltex Global FZC · client/company names (Solbar, Siberian Wellness, Agritech LLC, CARGILL Inc., DSM Andre Pectin, Aznar) · people's names · e-mails, phone numbers, postal addresses · patent numbers (BG 66235 B1, RU 2709384 C1, No. 113754) · standards (ISO 9001, ISO 22000, FSSC 22000, HACCP, GMP, FDA, FCC, USP, EP, Kosher/Halal as certification names) · abbreviations EPC, EPCM, PMC, CAPEX, OPEX, IRR, ROI, PFD, P&ID, BIM, FAT, CIP, SIP, SCADA, PLC, HVAC, SOP, COA, NSI, PDI, TDF, DP, FOS, HM, LM, MVR, BRIX, AISI 316L |
| Project names | Proper part stays in Latin script; generic descriptor is translated (e.g. "SIBERIAN WELLNESS PLANT" → RU "ЗАВОД SIBERIAN WELLNESS"). |
| Numbers | Values, ranges, units and percentages are copied exactly. Western digits (0–9) are used in all languages, including Arabic. |
| Arrows in text | "→" becomes "←" in Arabic (RTL). |
| Uppercase | Strings that are ALL CAPS in English are ALL CAPS in RU/TR/ES (CSS `uppercase` also applies). Chinese and Arabic have no letter case. |
